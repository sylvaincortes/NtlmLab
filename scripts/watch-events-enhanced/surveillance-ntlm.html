01À quoi ça sert

Une authentification Windows laisse des traces sur plusieurs machines à la fois, et lesquelles dépendent du protocole. Les examiner machine par machine, dans des observateurs d'événements séparés, oblige à recoller les horodatages de tête — exercice pénible et source d'erreurs.

Cet outil interroge toutes les machines depuis un seul poste et produit un flux unique, trié chronologiquement, avec une colonne indiquant la machine d'origine :

On lit ici, en cinq lignes et en moins d'une seconde, le trajet complet d'une authentification NTLM : le client qui émet, le contrôleur de domaine qui valide le mot de passe, le serveur qui ouvre la session.

Cas d'usage

  • Inventorier NTLM avant d'envisager de le restreindre : qui l'utilise encore, depuis quelle machine, vers quel serveur, et avec quelle application.
  • Diagnostiquer un échec d'authentification en voyant d'un coup d'œil sur quelle machine la chaîne se rompt.
  • Comprendre ou enseigner la différence entre NTLM et Kerberos, en observant que l'un fait intervenir le DC au moment de l'accès et l'autre non.
  • Vérifier une migration : s'assurer qu'une application bascule bien sur Kerberos après correction d'un SPN.

Ce que l'outil n'est pas

Ce n'est pas un SIEM. Il n'archive rien par défaut, ne corrèle pas sur la durée, ne produit pas d'alerte. Il affiche en direct et sait écrire un CSV. Pour une collecte pérenne sur un parc entier, utilisez Windows Event Forwarding ou un collecteur dédié — cet outil répond à la question « que se passe-t-il maintenant, et dans quel ordre ».

La différence structurante entre les deux protocoles

NTLM est un protocole de relais. Le serveur ne connaît pas le mot de passe et ne peut pas vérifier la réponse au défi : il transmet le triplet au contrôleur de domaine via le canal Netlogon et attend un verdict. Une authentification laisse donc des traces sur deux machines, plus le client.

Kerberos est un protocole à tickets. Le client obtient ses tickets auprès du DC avant de contacter le serveur, qui les valide seul avec la clé de son compte machine. Les traces côté DC sont donc antérieures à l'accès et concernent l'émission des tickets, pas l'accès lui-même.

02Principe de fonctionnement

Quatre mécanismes méritent d'être connus : ils expliquent le comportement de l'outil et évitent de mal interpréter ce qu'on voit.

Sessions persistantes

En transport WinRM, l'outil ouvre une session par machine au démarrage et la réutilise à chaque tour. Sans cela, chaque interrogation ouvrirait une nouvelle connexion, donc une nouvelle ouverture de session réseau sur la cible : un événement 4624 toutes les quelques secondes sur chaque machine surveillée. L'outil polluerait alors exactement ce qu'il est censé observer.

Si une session meurt, elle est jetée et recréée au tour suivant, sans interrompre la collecte sur les autres machines.

Collecte au plus près de la source

Le bloc de collecte s'exécute sur la machine distante et ne renvoie que des objets normalisés et légers, pas des enregistrements d'événements complets. Cela limite fortement le volume transféré, ce qui compte dès qu'on surveille plus de quelques machines.

Horodatages normalisés

La fenêtre de collecte est calculée sur chaque machine interrogée, pas sur le poste de supervision. Les heures sont converties en UTC pour le transport, puis réaffichées en heure locale du superviseur. Un décalage de fuseau horaire ne perturbe donc pas le tri.

Une dérive d'horloge réelle, en revanche, fausserait l'ordre apparent des événements. Les membres du domaine se synchronisent automatiquement sur le contrôleur de domaine ; en cas de doute, w32tm /query /status.

Déduplication par RecordId

L'outil interroge volontairement une fenêtre plus large que son intervalle — environ le double, plus dix secondes — pour ne rien manquer d'un événement écrit avec un léger retard. Les doublons sont éliminés à la réception grâce à la clé machine|journal|RecordId. Le cache est borné à 20 000 entrées pour qu'une session longue ne consomme pas indéfiniment de mémoire.

Mettre en place un compte d'audit non privilégié

Un administrateur lance le script de préparation une fois, en nommant le compte qui fera tourner la surveillance :

Sur chaque machine de la configuration, ce compte est ajouté à deux groupes locaux :

Les groupes sont désignés par leur SID, invariant quelle que soit la langue du système, et l'ajout passe par le fournisseur WinNT, qui fonctionne aussi bien sur un serveur membre que sur un contrôleur de domaine — où ces groupes sont des groupes de domaine local du conteneur Builtin.

Le point souvent négligé

Par défaut, seuls les administrateurs locaux peuvent ouvrir une session WinRM. Appartenir à Lecteurs des journaux d'événements ne suffit donc pas en WinRM : il faut aussi Utilisateurs de gestion à distance, sans quoi la session elle-même est refusée avant même d'avoir lu quoi que ce soit.

En transport RPC, le premier groupe suffit. Pour un compte d'audit en moindre privilège strict, RPC est donc le choix le plus économe.

Si vous n'êtes pas administrateur du domaine

Le script de préparation a besoin de droits d'administration sur les machines surveillées, pas sur le domaine entier. Être administrateur local de chacune suffit. Si vous ne les avez pas, demandez à qui de droit de lancer prepare-monitoring.ps1 -GrantAccessTo votre-compte.

04Mise en route

Trois étapes, dans cet ordre.

ÉTAPE 1

Déclarer les machines

Ouvrez watch-config.json et renseignez vos machines. Le chapitre 05 détaille chaque clé.

"machines": [
  { "name": "DCA.newgen.local",    "role": "dc",     "label": "Controleur de domaine" },
  { "name": "SRV25A.newgen.local", "role": "server", "label": "Serveur web" },
  { "name": "WIN11A.newgen.local", "role": "client", "label": "Poste de test" }
]
FQDN plutôt que nom NetBIOS, et surtout pas d'adresse IP

La connexion distante s'authentifie elle-même, et le nom fourni détermine le protocole retenu. Avec un FQDN, le client construit le SPN et obtient un ticket Kerberos. Avec une adresse IP, c'est impossible : la connexion retombe sur NTLM, et votre outil de surveillance NTLM génère alors lui-même du trafic NTLM à chaque interrogation.

Le nom court fonctionne en pratique, Windows complétant avec le suffixe DNS, mais dépend de cette complétion — ambiguë dans une forêt à plusieurs domaines.

ÉTAPE 2

Préparer les machines

une seule fois — administrateur local de chaque machine surveillée
.\prepare-monitoring.ps1
# ou, pour deleguer la surveillance a un compte non privilegie :
.\prepare-monitoring.ps1 -GrantAccessTo NEWGEN\svc-audit

Pour chaque machine de la configuration, le script enchaîne :

ÉtapeAction
1 Teste WinRM. S'il ne répond pas, lance Enable-PSRemoting à distance via WMI/DCOM — on ne peut pas utiliser WinRM pour activer WinRM — puis attend 20 secondes et re-teste.
2 Active les règles de pare-feu RemoteEventLogSvc*, qui fournissent le transport RPC de secours. Ciblées par nom interne, invariant quelle que soit la langue du système.
3 Avec -GrantAccessTo : ajoute le compte aux deux groupes locaux décrits au chapitre 03.
4 Active et dimensionne à 64 Mo les journaux NTLM/Operational et Security-Netlogon/Operational. Porte le journal Sécurité à 512 Mo, ou 1 Go s'il détecte un contrôleur de domaine.
5 Relève la politique d'audit et les clés NTLM, les compare au rôle déclaré, et signale précisément ce qui manquerait pour que les événements soient produits.
Ce qu'il ne fait pas, délibérément

Il ne modifie ni la politique d'audit ni les clés NTLM. Ces réglages touchent à LSA, ne sont effectifs qu'après redémarrage de la machine, et méritent une décision explicite. Le script se contente de vérifier et de vous dire quoi faire — voir le chapitre 09.

Le script est idempotent : relançable sans risque. -Check en fait un diagnostic pur, sans aucune modification.

09Activer l'audit sur les cibles

L'outil ne crée pas les événements, il les lit. Si l'audit n'est pas activé, la connexion réussira et l'affichage restera vide. prepare-monitoring.ps1 détecte ce cas et le signale, mais ne corrige pas : ces réglages touchent à LSA, ne sont effectifs qu'après redémarrage, et méritent une décision explicite.

Trois règles qui coûtent cher à ignorer

Les paramètres NTLM du registre ne sont lus qu'au démarrage. Tant que la machine n'a pas redémarré, lsass continue avec l'ancienne configuration. Les symptômes sont trompeurs : boucle d'invites, événement 4015, ou absence totale d'événement.

Netlogon doit être redémarré après modification de l'audit NTLM sur un contrôleur de domaine, faute de quoi rien n'apparaît.

Une GPO écrase le registre. Si vos réglages manuels disparaissent, cherchez la stratégie qui les impose plutôt que de les réappliquer.

Sur un serveur de ressources

# Audit des ouvertures de session (4624 / 4625)
auditpol /set /subcategory:"{0CCE9215-69AE-11D9-BED3-505054503030}" /success:enable /failure:enable

# Audit du trafic NTLM entrant (4022 / 4023) : 2 = tout auditer
Set-ItemProperty 'HKLM:\SYSTEM\CurrentControlSet\Control\Lsa\MSV1_0' `
  -Name AuditReceivingNTLMTraffic -Value 2 -Type DWord

Restart-Computer

Sur un poste client

# Audit du NTLM sortant (4020) : 0 = autoriser sans auditer,

La valeur 1 n'empêche rien

Elle se contente d'auditer ; seule la valeur 2 refuse réellement le NTLM sortant. Si vous observez un événement 4015 « Outgoing NTLM authentication traffic to remote servers that is blocked » après avoir mis 1, c'est que la machine n'a pas encore redémarré et que lsass applique l'ancienne valeur.

10Campagne d'inventaire NTLM

Le cas d'usage le plus utile de cet outil : établir qui utilise encore NTLM avant d'envisager de le restreindre. La démarche typique, en cinq temps.

Démarche d'inventaire
1
Activer l'audit
Sur les DC (AuditNTLMInDomain = 7) et sur les serveurs sensibles (AuditReceivingNTLMTraffic = 2). Sur les postes, RestrictSendingNTLMTraffic = 1 si vous voulez identifier les applications responsables.
2
Collecter dans la durée
-CsvPath sur plusieurs semaines, en couvrant les périodes de clôture et de maintenance où s'exécutent des traitements rares.
3
Identifier les couples et les applications
Quels clients vers quels serveurs, et avec quel binaire. Le champ Process Name des événements 4015 et 4020 désigne précisément le responsable.
4
Traiter les cas un par un
SPN manquant, accès par adresse IP, alias DNS sans SPN, application réellement incapable de faire du Kerberos. Les trois premiers se corrigent.
5
Basculer progressivement
Mode blocage par exceptions à l'aide de ClientAllowedNTLMServers et DCAllowedNTLMServers, avant d'envisager un refus généralisé.

Un angle mort à connaître

L'audit NTLM du DC ne voit que les authentifications de comptes de domaine. Les authentifications NTLM avec des comptes locaux se valident sur la machine cible, sans passer par le DC : seul l'audit du serveur de ressources (AuditReceivingNTLMTraffic) les révèle. Si vous ne surveillez que vos DC, vous les manquerez entièrement.

prepare-monitoring.ps1 — active WinRM et les journaux à distance, accorde les droits, vérifie l'audit par rôle 
#Requires -Version 5.1
<#
.SYNOPSIS
  Prepare toutes les machines declarees dans watch-config.json pour la
  surveillance centralisee : transport distant, journaux d'evenements,
  et verification de la politique d'audit.

.DESCRIPTION
  A executer UNE SEULE FOIS depuis le poste de supervision, avec un compte
  administrateur du domaine. Le script traite chaque machine de la liste :

    1. Teste WinRM. S'il ne repond pas, tente de l'activer a distance en
       lancant Enable-PSRemoting via WMI/DCOM, puis re-teste.
    2. Ouvre la regle de pare-feu "Gestion a distance du journal des
       evenements", qui fournit le transport RPC de secours.
    3. Active et dimensionne les journaux Microsoft-Windows-NTLM/Operational
       et Microsoft-Windows-Security-Netlogon/Operational, et agrandit le
       journal Securite.
    4. Releve la politique d'audit et les cles NTLM, et signale ce qui
       manquerait pour que les evenements soient reellement produits.

  Le script ne modifie PAS la politique d'audit ni les cles NTLM : c'est le
  role de setup-webserver.ps1, setup-dc.ps1 et setup-client.ps1. Il se contente
  de verifier et de vous dire quoi lancer.

.PARAMETER ConfigPath
  watch-config.json decrivant les machines. Par defaut a cote du script.

.PARAMETER Credential
  Compte administrateur du domaine. Par defaut, la session courante.

.PARAMETER Check
  Ne modifie rien, se contente du diagnostic.

.PARAMETER GrantAccessTo
  Compte a qui donner le droit de surveiller, sur chaque machine de la liste.
  Il est ajoute aux groupes locaux "Lecteurs des journaux d'evenements"
  (lecture du journal Securite a distance) et "Utilisateurs de gestion a
  distance" (ouverture de session WinRM sans etre administrateur).

  Permet de separer les roles : un administrateur lance ce script UNE FOIS,
  puis un compte d'audit non privilegie fait tourner watch-events-enhanced.ps1
  au quotidien.

  Format DOMAINE\compte, par exemple NEWGEN\svc-audit.

.NOTES
  PRIVILEGES REQUIS POUR CE SCRIPT : administrateur local de chaque machine
  surveillee. Il active WinRM, modifie des regles de pare-feu, redimensionne
  des journaux et, avec -GrantAccessTo, modifie des groupes locaux. Un
  administrateur du domaine remplit ces conditions partout.

  PRIVILEGES REQUIS POUR watch-events-enhanced.ps1 : beaucoup moins. Voir
  -GrantAccessTo ci-dessus.

.EXAMPLE
  .\prepare-monitoring.ps1
.EXAMPLE
  .\prepare-monitoring.ps1 -Check
.EXAMPLE
  .\prepare-monitoring.ps1 -GrantAccessTo NEWGEN\svc-audit
.EXAMPLE
  .\prepare-monitoring.ps1 -Credential (Get-Credential NEWGEN\Administrator)
#>

function Title($t) { Write-Host "`n$t" -ForegroundColor Cyan; Write-Host ('-' * 78) -ForegroundColor DarkGray }

$Configure = {
    param([bool]$ReadOnly, [string]$GrantTo)

    $r = [ordered]@{
        Computer   = $env:COMPUTERNAME
        Os         = (Get-CimInstance Win32_OperatingSystem).Caption
        IsDC       = $false
        Changes    = @()
        Problems   = @()
        Logs       = @{}
        Audit      = @{}
        Ntlm       = @{}
    }

    try {
        # ProductType 2 = controleur de domaine
        $r.IsDC = ((Get-CimInstance Win32_OperatingSystem).ProductType -eq 2)
    } catch { }

    # ---- 1. Regle de pare-feu RPC (transport de secours) ----
    try {
        # On cible les regles par leur NOM interne (invariant) et non par leur
        # libelle, qui est traduit : "Gestion a distance du journal des
        # evenements" sur un Windows francais.
        $grp = Get-NetFirewallRule -Name 'RemoteEventLogSvc*' -ErrorAction SilentlyContinue
        if ($grp) {
            $off = @($grp | Where-Object { $_.Enabled -ne 'True' })
            if ($off.Count -eq 0) {
                $r.Changes += 'pare-feu RPC : deja ouvert'
            } elseif ($ReadOnly) {
                $r.Problems += "pare-feu RPC : $($off.Count) regle(s) desactivee(s)"
            } else {
                $off | Enable-NetFirewallRule
                $r.Changes += "pare-feu RPC : $($off.Count) regle(s) activee(s)"
            }
        } else {
            $r.Problems += 'regles de pare-feu RemoteEventLogSvc introuvables'
        }
    } catch {
        $r.Problems += "pare-feu : $($_.Exception.Message)"
    }

    # ---- 2. Journaux d'evenements ----
    $wanted = @(
        @{ Name = 'Microsoft-Windows-NTLM/Operational';              Size = 67108864 }
        @{ Name = 'Microsoft-Windows-Security-Netlogon/Operational'; Size = 67108864 }
    )
    foreach ($w in $wanted) {
        try {
            $cfgTxt = (& wevtutil gl $w.Name 2>&1) -join "`n"
            if ($LASTEXITCODE -ne 0 -or $cfgTxt -match 'Impossible|not be found|introuvable') {
                $r.Logs[$w.Name] = 'absent sur cette version de Windows'
                continue
            }
            $enabled = ($cfgTxt -match 'enabled:\s*true')
            $size = if ($cfgTxt -match 'maxSize:\s*(\d+)') { [int64]$Matches[1] } else { 0 }

            if ($enabled -and $size -ge $w.Size) {
                $r.Logs[$w.Name] = "actif, $([int]($size/1MB)) Mo"
            } elseif ($ReadOnly) {
                $r.Logs[$w.Name] = "a corriger (actif=$enabled, $([int]($size/1MB)) Mo)"
            } else {
                if (-not $enabled) { & wevtutil sl $w.Name /e:true 2>&1 | Out-Null }
                if ($size -lt $w.Size) { & wevtutil sl $w.Name /ms:$($w.Size) 2>&1 | Out-Null }
                $r.Logs[$w.Name] = 'active et dimensionne'
                $r.Changes += "journal $($w.Name) configure"
            }
        } catch {
            $r.Logs[$w.Name] = "erreur : $($_.Exception.Message)"
        }
    }

    # Journal Securite : 512 Mo, 1 Go sur un DC
    try {
        $target = if ($r.IsDC) { 1073741824 } else { 536870912 }
        $secTxt = (& wevtutil gl Security 2>&1) -join "`n"
        $secSize = if ($secTxt -match 'maxSize:\s*(\d+)') { [int64]$Matches[1] } else { 0 }
        if ($secSize -ge $target) {
            $r.Logs['Security'] = "$([int]($secSize/1MB)) Mo"
        } elseif ($ReadOnly) {
            $r.Logs['Security'] = "$([int]($secSize/1MB)) Mo (a agrandir)"
        } else {
            & wevtutil sl Security /ms:$target 2>&1 | Out-Null
            $r.Logs['Security'] = "porte a $([int]($target/1MB)) Mo"
            $r.Changes += 'journal Securite agrandi'
        }
    } catch {
        $r.Logs['Security'] = "erreur : $($_.Exception.Message)"
    }

    # ---- 2 bis. Droits du compte d'audit ----
    # Les groupes sont designes par leur SID connu, invariant quelle que soit
    # la langue du systeme :
    #   S-1-5-32-573  Lecteurs des journaux d'evenements
    #   S-1-5-32-580  Utilisateurs de gestion a distance (WinRM sans admin)
    # L'acces se fait par le fournisseur WinNT, qui fonctionne aussi bien sur
    # un serveur membre que sur un controleur de domaine, ou ces groupes sont
    # des groupes de domaine local du conteneur Builtin.
    if ($GrantTo) {
        $acct = $GrantTo.Split('\')[-1]
        $adom = if ($GrantTo -match '\\') { $GrantTo.Split('\')[0] } else { $env:USERDOMAIN }

        foreach ($wk in @(
            @{ Sid = 'S-1-5-32-573'; Why = 'lecture du journal Securite a distance' }
            @{ Sid = 'S-1-5-32-580'; Why = 'ouverture de session WinRM sans etre administrateur' }
        )) {
            try {
                $sidObj = New-Object System.Security.Principal.SecurityIdentifier($wk.Sid)
                $gName = ($sidObj.Translate([System.Security.Principal.NTAccount]).Value -split '\\')[-1]
                $grpObj = [ADSI]"WinNT://$env:COMPUTERNAME/$gName,group"

                $members = @()
                try {
                    foreach ($mb in @($grpObj.psbase.Invoke('Members'))) {
                        $members += $mb.GetType().InvokeMember('Name', 'GetProperty', $null, $mb, $null)
                    }
                } catch { }

                if ($members -contains $acct) {
                    $r.Changes += "$gName : $GrantTo deja membre"
                } elseif ($ReadOnly) {
                    $r.Problems += "$gName : $GrantTo n'est pas membre ($($wk.Why))"
                } else {
                    $grpObj.Add("WinNT://$adom/$acct,user")
                    $r.Changes += "$gName : $GrantTo ajoute ($($wk.Why))"
                }
            } catch {
                $r.Problems += "groupe $($wk.Sid) : $($_.Exception.Message)"
            }
        }
    }

    # ---- 3. Releve de la politique d'audit (lecture seule) ----
    # GUID de la categorie Logon/Logoff : insensible a la langue du systeme.
    try {
        # Les sous-categories sont elles aussi designees par GUID, ce qui evite
        # de dependre du libelle traduit.
        #   0CCE9215  Logon                 (Ouverture de session)
        #   0CCE923F  Credential Validation (Validation des informations d'identification)
        $pol = (& auditpol /get /subcategory:"{0CCE9215-69AE-11D9-BED3-505054503030}" 2>&1) -join "`n"
        if ($pol -match '(?m)^\s*\S.*?\s{2,}(\S.*?)\s*$' -and $pol -notmatch 'error|erreur') {
            # Derniere ligne non vide : "<sous-categorie>   <reglage>"
            $last = ($pol -split "`n" | Where-Object { $_ -match '\S' })[-1]
            if ($last -match '\s{2,}(\S.*?)\s*$') { $r.Audit['Logon'] = $Matches[1].Trim() }
        }
        if (-not $r.Audit['Logon']) { $r.Audit['Logon'] = 'indetermine' }
    } catch { $r.Audit['Logon'] = "erreur : $($_.Exception.Message)" }

    if ($r.IsDC) {
        try {
            $pol2 = (& auditpol /get /subcategory:"{0CCE923F-69AE-11D9-BED3-505054503030}" 2>&1) -join "`n"
            $last2 = ($pol2 -split "`n" | Where-Object { $_ -match '\S' })[-1]
            if ($last2 -match '\s{2,}(\S.*?)\s*$') { $r.Audit['CredentialValidation'] = $Matches[1].Trim() }
            if (-not $r.Audit['CredentialValidation']) { $r.Audit['CredentialValidation'] = 'indetermine' }
        } catch { }
    }

    # ---- 4. Releve des cles NTLM (lecture seule) ----
    $msv = 'HKLM:\SYSTEM\CurrentControlSet\Control\Lsa\MSV1_0'
    $lsa = 'HKLM:\SYSTEM\CurrentControlSet\Control\Lsa'
    $net = 'HKLM:\SYSTEM\CurrentControlSet\Services\Netlogon\Parameters'
    function Reg($p, $n) { try { (Get-ItemProperty $p -Name $n -ErrorAction Stop).$n } catch { $null } }

    $r.Ntlm['LmCompatibilityLevel']       = Reg $lsa 'LmCompatibilityLevel'
    $r.Ntlm['AuditReceivingNTLMTraffic']  = Reg $msv 'AuditReceivingNTLMTraffic'
    $r.Ntlm['RestrictSendingNTLMTraffic'] = Reg $msv 'RestrictSendingNTLMTraffic'
    if ($r.IsDC) { $r.Ntlm['AuditNTLMInDomain'] = Reg $net 'AuditNTLMInDomain' }

    [pscustomobject]$r
}

function Enable-WinRMViaDcom {
    <#  Amorcage : WinRM est injoignable, on lance Enable-PSRemoting sur la
        cible en creant un processus via WMI/DCOM (ports 135 + dynamiques).
        Necessite des droits d'administrateur sur la machine distante.       #>
    param([string]$Name)
    try {
        $opt = New-CimSessionOption -Protocol Dcom
        $p = @{ ComputerName = $Name; SessionOption = $opt; ErrorAction = 'Stop' }
        if ($Credential) { $p['Credential'] = $Credential }
        $cs = New-CimSession @p

        $cmd = 'powershell.exe -NoProfile -ExecutionPolicy Bypass -Command ' +
               '"Enable-PSRemoting -Force -SkipNetworkProfileCheck; ' +
               'Set-Service WinRM -StartupType Automatic; Start-Service WinRM"'

        $res = Invoke-CimMethod -CimSession $cs -ClassName Win32_Process `
                                -MethodName Create -Arguments @{ CommandLine = $cmd } -ErrorAction Stop
        Remove-CimSession $cs -ErrorAction SilentlyContinue
        return ($res.ReturnValue -eq 0)
    } catch {
        $script:lastDcomError = $_.Exception.Message
        return $false
    }
}

# 2. Collecteur
#    Execute sur la machine distante (WinRM) ou localement en ciblant la
#    machine distante (RPC). Il renvoie des objets legers deja normalises
#    plutot que des EventRecord complets, ce qui limite fortement le volume
#    transfere sur le reseau.

$Collector = {
    param(
        [string]$Role,
        [int]$LookbackSeconds,
        [string]$TargetComputer   # vide = machine locale
    )

    # Journaux et identifiants a interroger selon le role de la machine.
    $plan = switch ($Role) {
        'dc' {
            @(
                @{ Log = 'Security'; Ids = @(4624, 4625, 4768, 4769, 4771, 4776); Msg = $false }
                @{ Log = 'Microsoft-Windows-Security-Netlogon/Operational'; Ids = @(); Msg = $true }
                @{ Log = 'Microsoft-Windows-NTLM/Operational'; Ids = @(); Msg = $true }
            )
        }
        'client' {
            @(
                @{ Log = 'Microsoft-Windows-NTLM/Operational'; Ids = @(); Msg = $true }
                @{ Log = 'Security'; Ids = @(4648, 4624, 4625); Msg = $false }
            )
        }
        'auto' {
            # Union de tous les journaux : les journaux absents sur la machine
            # sont simplement ignores (ErrorAction SilentlyContinue).
            @(
                @{ Log = 'Security'; Ids = @(4624, 4625, 4648, 4672, 4768, 4769, 4771, 4776); Msg = $false }
                @{ Log = 'Microsoft-Windows-Security-Netlogon/Operational'; Ids = @(); Msg = $true }
                @{ Log = 'Microsoft-Windows-NTLM/Operational'; Ids = @(); Msg = $true }
            )
        }
        default {
            @(
                @{ Log = 'Security'; Ids = @(4624, 4625, 4648, 4672); Msg = $false }
                @{ Log = 'Microsoft-Windows-NTLM/Operational'; Ids = @(); Msg = $true }
            )
        }
    }

    # StartTime est calcule SUR la machine interrogee : cela evite tout probleme
    # de decalage d'horloge ou de fuseau entre le superviseur et les cibles.
    $start = (Get-Date).AddSeconds(-$LookbackSeconds)
    $out = New-Object System.Collections.ArrayList

    foreach ($p in $plan) {
        $hash = @{ LogName = $p.Log; StartTime = $start }
        if ($p.Ids.Count -gt 0) { $hash['Id'] = $p.Ids }

        $params = @{ FilterHashtable = $hash; ErrorAction = 'SilentlyContinue'; MaxEvents = 300 }
        if ($TargetComputer) { $params['ComputerName'] = $TargetComputer }

        $events = @(Get-WinEvent @params)

        foreach ($e in $events) {
            # EventData -> table de hachage nom/valeur
            $data = @{}
            try {
                $x = [xml]$e.ToXml()
                foreach ($n in $x.Event.EventData.Data) {
                    if ($n.Name) { $data[$n.Name] = [string]$n.'#text' }
                }
            } catch { }

            # Les journaux operationnels NTLM et Netlogon portent l'information
            # utile dans le texte du message, pas dans EventData.
            $msg = $null
            if ($p.Msg) {
                try { $msg = ($e.Message -replace '\s+', ' ') } catch { }
            }

            [void]$out.Add([pscustomobject]@{
                RecordId = $e.RecordId
                TimeUtc  = $e.TimeCreated.ToUniversalTime()
                Id       = $e.Id
                Log      = $p.Log
                Data     = $data
                Message  = $msg
            })
        }
    }

    $out
}

# 3. Normalisation : transformer un evenement brut en ligne affichable

function Get-NormalizedRecord {
    param($Raw, [string]$Machine, [string]$Role)

    $d   = $Raw.Data
    $m   = $Raw.Message
    $id  = [int]$Raw.Id

    function Field([string]$k) { if ($d.ContainsKey($k) -and $d[$k]) { $d[$k] } else { '' } }
    function FromMsg([string]$pattern) {
        if ($m -and $m -match $pattern) { $Matches[1] } else { '' }
    }

    $proto  = ''
    $kind   = 'Autre'      # NTLM | Kerberos | Autre
    $ok     = $true
    $user   = ''
    $dom    = ''
    $ip     = ''
    $detail = ''

    switch ($id) {

        # ---------- Journal Securite ----------
        4624 {
            $user = Field 'TargetUserName'; $dom = Field 'TargetDomainName'
            $ip   = Field 'IpAddress'
            $pkg  = Field 'AuthenticationPackageName'
            $lm   = Field 'LmPackageName'
            $lp   = (Field 'LogonProcessName').Trim()
            $type = Field 'LogonType'

            $proto = if ($lm -and $lm -ne '-') { "$pkg / $lm" } else { $pkg }
            $kind  = if ($pkg -match 'NTLM' -or $lp -eq 'NtLmSsp') { 'NTLM' }
                     elseif ($pkg -match 'Kerberos') { 'Kerberos' }
                     else { 'Autre' }
            $detail = "ouverture type=$type proc=$lp logonId=$(Field 'TargetLogonId')"
            if (Field 'KeyLength') { $detail += " cle=$(Field 'KeyLength')" }
            if (Field 'WorkstationName') { $detail += " poste=$(Field 'WorkstationName')" }
        }
        4625 {
            $user = Field 'TargetUserName'; $dom = Field 'TargetDomainName'
            $ip   = Field 'IpAddress'
            $pkg  = Field 'AuthenticationPackageName'
            $proto = $pkg; $ok = $false
            $kind = if ($pkg -match 'NTLM') { 'NTLM' } elseif ($pkg -match 'Kerberos') { 'Kerberos' } else { 'Autre' }
            $detail = "ECHEC type=$(Field 'LogonType') status=$(Field 'Status') sub=$(Field 'SubStatus')"
        }
        4648 {
            $user = Field 'TargetUserName'; $dom = Field 'TargetDomainName'
            $ip   = Field 'IpAddress'
            $proto = 'Identifiants explicites'
            $detail = "vers $(Field 'TargetServerName') par $(Field 'SubjectUserName')"
        }
        4672 {
            $user = Field 'SubjectUserName'; $dom = Field 'SubjectDomainName'
            $proto = 'Privileges speciaux'
            $detail = "logonId=$(Field 'SubjectLogonId')"
        }
        4768 {
            $user = Field 'TargetUserName'; $dom = Field 'TargetDomainName'
            $ip   = Field 'IpAddress'
            $proto = 'Kerberos TGT'; $kind = 'Kerberos'
            $ok = ((Field 'Status') -in @('0x0', '0x00000000', ''))
            $detail = "AS-REQ status=$(Field 'Status') chiffrement=$(Field 'TicketEncryptionType')"
        }
        4769 {
            $user = Field 'TargetUserName'; $dom = Field 'TargetDomainName'
            $ip   = Field 'IpAddress'
            $proto = 'Kerberos TGS'; $kind = 'Kerberos'
            $ok = ((Field 'Status') -in @('0x0', '0x00000000', ''))
            $detail = "service=$(Field 'ServiceName') status=$(Field 'Status')"
        }
        4771 {
            $user = Field 'TargetUserName'
            $ip   = Field 'IpAddress'
            $proto = 'Kerberos pre-auth'; $kind = 'Kerberos'; $ok = $false
            $detail = "ECHEC code=$(Field 'Status')"
        }
        4776 {
            $user = Field 'TargetUserName'
            $proto = 'NTLM validation DC'; $kind = 'NTLM'
            $err = Field 'Status'
            $ok = ($err -in @('0x0', '0x00000000', ''))
            $detail = "poste=$(Field 'Workstation') erreur=$err pkg=$(Field 'PackageName')"
        }

        # ---------- Journaux operationnels : NTLM et Security-Netlogon ----------
        # Server 2025 / Windows 11 : 4015, 4020-4023 (NTLM), 4030-4033 (Netlogon).
        # Versions anterieures : 8001-8004 (NTLM).
        default {
            # "(NULL)" et "Null" sont les marqueurs d'absence de ces journaux.
            function Clean([string]$v) {
                if ($v -in @('(NULL)', 'NULL', 'Null', 'null', '-')) { '' } else { $v }
            }

            $user = Clean (FromMsg 'Supplied user:\s*(\S+)')
            if (-not $user) { $user = Clean (FromMsg 'Username:\s*(\S+)') }
            # Sur un 4015, "Supplied user" est souvent vide alors que l'identite
            # du processus appelant, elle, est connue : c'est elle qui compte.
            if (-not $user) { $user = Clean (FromMsg 'User identity of client process:\s*(\S+)') }
            if (-not $user) { $user = Clean (Field 'UserName') }

            $dom = Clean (FromMsg 'Supplied domain:\s*(\S+)')
            if (-not $dom) { $dom = Clean (FromMsg 'Domain name of user identity of client process:\s*(\S+)') }
            if (-not $dom) { $dom = Clean (FromMsg 'Domain:\s*(\S+)') }
            $ip  = Clean (FromMsg 'Client IP:\s*(\S+)')

            $ver  = FromMsg 'NTLM Version:\s*(\S+)'
            $st   = FromMsg 'Status:\s*(0x\S+)'
            $tgt  = Clean (FromMsg 'Target server:\s*(\S+)')
            # Les chemins de processus contiennent des espaces : on borne la
            # capture sur le libelle suivant plutot que sur le premier espace.
            $proc = FromMsg 'Name of client process:\s*(.+?)\s+LUID of client process:'
            if (-not $proc) { $proc = FromMsg 'Process Name:\s*(.+?)\s+Process PID:' }
            if ($proc) { $proc = ($proc -split '\\')[-1] }

            $kind = 'NTLM'
            switch ($id) {
                4015 { $proto = 'NTLM sortant BLOQUE'; $ok = $false }
                4020 { $proto = 'NTLM sortant' }
                4021 { $proto = 'NTLM sortant (alerte)'; $ok = $false }
                4022 { $proto = 'NTLM entrant' }
                4023 { $proto = 'NTLM entrant ECHEC'; $ok = $false }
                4030 { $proto = 'NTLM DC inter-domaines' }
                4031 { $proto = 'NTLM DC inter-dom. ECHEC'; $ok = $false }
                4032 { $proto = 'NTLM DC validation' }
                4033 { $proto = 'NTLM DC validation ECHEC'; $ok = $false }
                8001 { $proto = 'NTLM sortant (legacy)' }
                8002 { $proto = 'NTLM sortant bloque (legacy)'; $ok = $false }
                8003 { $proto = 'NTLM entrant (legacy)' }
                8004 { $proto = 'NTLM domaine (legacy)' }
                default { $proto = "evt $id"; $kind = 'Autre' }
            }
            if ($st -and $st -notmatch '^0x0+$') { $ok = $false }

            $bits = @()
            if ($ver)  { $bits += $ver }
            if ($tgt)  { $bits += "cible=$tgt" }
            if ($proc) { $bits += "proc=$proc" }
            if ($st)   { $bits += "status=$st" }
            if (-not $bits -and $d.Count) {
                $bits += ($d.GetEnumerator() | ForEach-Object { "$($_.Key)=$($_.Value)" }) -join ' '
            }
            $detail = $bits -join ' '
        }
    }

    [pscustomobject]@{
        Time     = $Raw.TimeUtc.ToLocalTime()
        Machine  = $Machine
        Role     = $Role
        Id       = $id
        Protocol = $proto
        Kind     = $kind
        Success  = $ok
        User     = $user
        Domain   = $dom
        Ip       = $ip
        Detail   = $detail
    }
}

function Test-Keep {
    param($R)

    $u = $R.User
    if (-not $u -or $u -eq '-') { return $false }
    if ($ignoreMachineAccts -and $u -match '\$$') { return $false }
    foreach ($a in $ignoreAccounts) { if ($u -eq $a) { return $false } }

    if ($ignoreLogonTypes.Count -and $R.Detail -match 'type=(\d+)') {
        if ($Matches[1] -in $ignoreLogonTypes) { return $false }
    }
    # Adresses a masquer : typiquement celle du poste de supervision, dont les
    # connexions d'administration ne sont pas le sujet de l'observation.
    if ($ignoreSourceIps.Count -and $R.Ip) {
        foreach ($x in $ignoreSourceIps) { if ($R.Ip -eq $x) { return $false } }
    }
    if ($onlyUsers.Count) {
        $hit = $false
        foreach ($p in $onlyUsers) { if ($u -like "*$p*") { $hit = $true; break } }
        if (-not $hit) { return $false }
    }
    if ($onlyProtocols.Count -and $R.Kind -notin $onlyProtocols) { return $false }

    return $true
}

$machines = @(foreach ($m in $cfg.machines) {
    [pscustomobject]@{
        Name      = [string]$m.name
        Short     = ([string]$m.name).Split('.')[0].ToUpper()
        Role      = if ($m.role) { [string]$m.role } else { 'server' }
        Label     = if ($m.label) { [string]$m.label } else { '' }
        Transport = if ($m.transport) { [string]$m.transport } else { $defaultTranspt }
        Online    = $false
        LastError = ''
        Session   = $null
    }
})

function Get-MachineSession {
    <#  Session WinRM PERSISTANTE, creee une fois et reutilisee a chaque tour.

        Sans cela, chaque interrogation ouvrirait une nouvelle connexion, donc
        une nouvelle ouverture de session reseau sur la cible : un evenement
        4624 toutes les quelques secondes sur chaque machine surveillee. L'outil
        polluerait alors exactement ce qu'il est cense observer.               #>
    param($M)

    if ($M.Session -and $M.Session.State -eq 'Opened') { return $M.Session }
    if ($M.Session) {
        try { Remove-PSSession $M.Session -ErrorAction SilentlyContinue } catch { }
        $M.Session = $null
    }
    $p = @{ ComputerName = $M.Name; ErrorAction = 'Stop' }
    if ($Credential) { $p['Credential'] = $Credential }
    $M.Session = New-PSSession @p
    return $M.Session
}

function Close-MachineSessions {
    foreach ($m in $machines) {
        if ($m.Session) {
            try { Remove-PSSession $m.Session -ErrorAction SilentlyContinue } catch { }
            $m.Session = $null
        }
    }
}

function Invoke-Collect {
    <#  Execute le collecteur contre une machine, quel que soit le transport.

        Renvoie TOUJOURS un tableau en cas de succes, eventuellement vide, et
        $null uniquement en cas d'echec de connexion. Cette distinction est
        essentielle : une machine sans evenement n'est pas une machine
        injoignable.                                                           #>
    param($M, [int]$Lookback)

    $isLocal = ($M.Short -eq $env:COMPUTERNAME.ToUpper())

    try {
        $out = if ($isLocal) {
            & $Collector $M.Role $Lookback ''
        } elseif ($M.Transport -eq 'RPC') {
            & $Collector $M.Role $Lookback $M.Name
        } else {
            $s = Get-MachineSession -M $M
            Invoke-Command -Session $s -ScriptBlock $Collector `
                           -ArgumentList @($M.Role, $Lookback, '') -ErrorAction Stop
        }

        $M.LastError = ''
        # @($null) produirait un tableau d'un element nul : on teste avant.
        if ($null -eq $out) { return , @() }
        return , @($out)
    } catch {
        $M.LastError = $_.Exception.Message
        # La session est peut-etre morte : on la jette pour forcer une
        # reconnexion propre au prochain essai.
        if ($M.Session) {
            try { Remove-PSSession $M.Session -ErrorAction SilentlyContinue } catch { }
            $M.Session = $null
        }
        return $null
    }
}

function Info2($t) { Write-Host "  $t" -ForegroundColor DarkGray }

function Test-Machines {
    Write-Host ''
    Write-Host 'Verification des machines' -ForegroundColor Cyan
    Write-Host ('-' * 78) -ForegroundColor DarkGray

    foreach ($m in $machines) {
        $tag = if ($m.Label) { " ($($m.Label))" } else { '' }
        Write-Host ("  {0,-26} {1,-7} {2,-6} " -f $m.Name, $m.Role, $m.Transport) -NoNewline

        $res = Invoke-Collect -M $m -Lookback 120
        if ($null -eq $res) {
            $m.Online = $false
            Write-Host 'INJOIGNABLE' -ForegroundColor Red
            Write-Host ("      -> " + $m.LastError) -ForegroundColor DarkGray
        } else {
            $m.Online = $true
            Write-Host ("OK  ({0} evenement(s) sur 2 min)$tag" -f @($res).Count) -ForegroundColor Green
        }
    }

    $up = @($machines | Where-Object Online).Count
    Write-Host ('-' * 78) -ForegroundColor DarkGray
    Write-Host ("  {0}/{1} machine(s) joignable(s)" -f $up, $machines.Count) `
        -ForegroundColor $(if ($up -eq $machines.Count) { 'Green' } elseif ($up) { 'Yellow' } else { 'Red' })
    $keep = @($machines | Where-Object { $_.Session }).Count
    if ($keep) { Info2 "$keep session(s) WinRM persistante(s) ouverte(s), reutilisees a chaque tour" }

    if ($up -lt $machines.Count) {
        Write-Host ''
        Write-Host '  Pistes en cas d''echec :' -ForegroundColor Yellow
        Write-Host '    - WinRM non active sur la cible      : Enable-PSRemoting -Force'
        Write-Host '    - droits insuffisants                : ajouter le compte au groupe local'
        Write-Host '                                           "Lecteurs des journaux d''evenements"'
        Write-Host '    - pare-feu                           : autoriser WinRM (5985) ou, en RPC,'
        Write-Host '                                           "Gestion a distance du journal des evenements"'
        Write-Host '    - machine hors domaine               : renseigner -Credential'
    }
    Write-Host ''
}

Write-Host ''
Write-Host '  Surveillance centralisee NTLM / Kerberos' -ForegroundColor Cyan

if ($cfg.domain) { Write-Host "  domaine       : $($cfg.domain)" -ForegroundColor DarkGray }

Test-Machines

if ($TestOnly) { Close-MachineSessions; return }

$online = @($machines | Where-Object Online)
if ($online.Count -eq 0) { throw 'Aucune machine joignable, arret.' }

# Deduplication : cle "machine|journal|recordid". Bornee pour ne pas croitre
# indefiniment sur une session longue.
$seen = New-Object 'System.Collections.Generic.HashSet[string]'
$seenOrder = New-Object System.Collections.Queue
$seenMax = 20000

function Register-Seen {
    param([string]$Key)
    if ($seen.Contains($Key)) { return $false }
    [void]$seen.Add($Key)
    $seenOrder.Enqueue($Key)
    while ($seenOrder.Count -gt $seenMax) { [void]$seen.Remove($seenOrder.Dequeue()) }
    return $true
}

$stats = @{ Total = 0; NTLM = 0; Kerberos = 0; Echecs = 0 }
$firstPass = $true
$tick = 0
# Recouvrement : on reinterroge plus large que l'intervalle, la deduplication
# se charge d'eliminer les doublons. Evite de manquer un evenement ecrit avec
# un leger decalage.
$lookback = [Math]::Max($interval * 2 + 10, 30)

Write-Header
Write-Host '  Ctrl+C pour arreter' -ForegroundColor DarkGray

try {
    while ($true) {
        $batch = New-Object System.Collections.ArrayList
        $lb = if ($firstPass) { [Math]::Max($backfillMin * 60, $lookback) } else { $lookback }

        foreach ($m in $online) {
            $raws = Invoke-Collect -M $m -Lookback $lb
            if ($null -eq $raws) {
                if ($m.Online) {
                    $m.Online = $false
                    Write-Host ("  [!] {0} ne repond plus : {1}" -f $m.Short, $m.LastError) -ForegroundColor Red
                }
                continue
            }
            foreach ($raw in @($raws)) {
                $key = '{0}|{1}|{2}' -f $m.Short, $raw.Log, $raw.RecordId
                if (-not (Register-Seen $key)) { continue }

                $rec = Get-NormalizedRecord -Raw $raw -Machine $m.Short -Role $m.Role
                if (Test-Keep $rec) { [void]$batch.Add($rec) }
            }
        }

        # Tri chronologique global : c'est tout l'interet de la vue centralisee,
        # voir s'enchainer client -> serveur -> DC dans le bon ordre.
        foreach ($r in ($batch | Sort-Object Time)) {
            Write-Record $r
            $stats.Total++
            if ($r.Kind -eq 'NTLM')     { $stats.NTLM++ }
            if ($r.Kind -eq 'Kerberos') { $stats.Kerberos++ }
            if (-not $r.Success)        { $stats.Echecs++ }

            if ($CsvPath) {
                try {
                    $r | Select-Object Time, Machine, Role, Id, Protocol, Kind, Success, User, Domain, Ip, Detail |
                        Export-Csv -Path $CsvPath -Append -NoTypeInformation -Encoding UTF8
                } catch {
                    Write-Host "  [!] ecriture CSV impossible : $($_.Exception.Message)" -ForegroundColor Red
                    $CsvPath = $null
                }
            }
        }

        if ($firstPass) {
            $firstPass = $false
            Write-Host ('  --- fin de l''historique, surveillance en direct ---') -ForegroundColor DarkGray
        }

        # Reprise des machines tombees, testee une iteration sur six pour ne pas
        # payer un delai d'expiration a chaque tour.
        $tick++
        if ($tick % 6 -eq 0) {
            $down = @($machines | Where-Object { -not $_.Online })
            foreach ($m in $down) {
                if ($null -ne (Invoke-Collect -M $m -Lookback 60)) {
                    $m.Online = $true
                    Write-Host ("  [+] {0} de nouveau joignable" -f $m.Short) -ForegroundColor Green
                }
            }
            if ($down.Count) { $online = @($machines | Where-Object Online) }
        }

        Start-Sleep -Seconds $interval
    }
}
finally {
    Close-MachineSessions
    Write-Host ''
    Write-Host ('-' * 78) -ForegroundColor DarkGray
    Write-Host ("  {0} evenement(s) affiche(s)  -  NTLM {1}  |  Kerberos {2}  |  echecs {3}" -f `
        $stats.Total, $stats.NTLM, $stats.Kerberos, $stats.Echecs) -ForegroundColor Cyan
    if ($CsvPath -and (Test-Path $CsvPath)) {
        Write-Host "  CSV : $CsvPath" -ForegroundColor DarkGray
    }
    Write-Host ''
}
